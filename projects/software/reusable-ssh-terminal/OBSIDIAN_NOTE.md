# Reusable SSH Terminal
GitHub: https://github.com/ZeusGriffin/open-design/tree/main/projects/software/reusable-ssh-terminal
Sources: https://github.com/madeye/gterm and https://github.com/sigman78/esperdeck
Goal: iPhone 15 CyberDeck SSH terminal first; reusable settings/interfaces for Pi, Windows, Cardputer ADV and ESP32.
Next: inspect/pin upstream, select iOS baseline, compile, connect to authorized LAN test host.
Security: never store passwords in repo; verify SSH host keys; keep private keys in device secure storage.
