# JUKEBOXX — Design Album Rollout

**Working artist:** Johnny Jukebox  
**Review tool:** [[JUKE View — Review Workflow]]

## Goal
Create a consistent, high-quality album rollout using one organized source library, selected visual identity, and repeatable review/approval process. Maintain a clear distinction between original art, AI exploration, and approved finals.

## Collection inbox
- [ ] Upload artist photographs and approved likeness references
- [ ] Upload logos, illustrations, sketches and brand references
- [ ] Upload music titles, track order and release information
- [ ] Upload inspirations, visual examples and typography references
- [ ] Record rights/permissions and required credits per asset
- [ ] Mark which sources are approved for AI use

1. Johnny Jukebox — artist introduction
2. Identity and artistic positioning
3. Visual moodboard and references

6. Single artwork and album cover family
7. Teasers, reels, social and motion
8. Press kit, merch and live visuals
9. Release calendar and deliverable owners
10. Final creative approvals

## Review procedure
1. Open `index.html` from the JUKE View GitHub project.
2. Load media into JUKE View.
3. Circle, highlight and number specific change requests.
4. Export a review JSON, and a PNG for image boards.
5. File reviews with source version and date; do not overwrite originals.
6. Only approved revisions become locked source for next phase.

## Naming convention
`JUKEBOXX_[asset]_[concept]_[v##]_[YYYY-MM-DD]`

## Boundaries
No public release or AI alteration of artist images without confirmation of appropriate permissions. No confidential or unrelated work files in the public GitHub repository.
