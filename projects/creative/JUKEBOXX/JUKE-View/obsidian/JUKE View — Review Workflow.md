# JUKE View — Review Workflow

**Open:** [JUKE View HTML](https://github.com/ZeusGriffin/open-design/blob/main/projects/creative/JUKEBOXX/JUKE-View/index.html) — download file, then open locally.

## Input
- Images: PNG, JPG, SVG, WEBP, GIF
- References: PDF, HTML, TXT, MD
- More file formats and rich deck previews belong to later versions

## Markup
- **Pen:** draw freehand
- **Circle / Box:** mark target regions precisely
- **Highlight:** translucent emphasis
- **Note:** type request on the right and tap location in the artwork
- **Erase / Undo:** remove marks without changing source image
- **Review notes:** edit or delete individual feedback
- **Artboard:** switch square, portrait, story or wide views

## Output / approvals
- Export JSON, preserving notes, coordinates and marks.
- For image boards, export a marked-up PNG.
- Keep the original file and exported JSON together by version.
- Re-upload originals to a restarted JUKE View session, then import JSON.
- Keep the **sample design unapproved** until explicitly chosen.
