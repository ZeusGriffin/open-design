# JUKEBOXX visual direction

## Confirmed requirements

- Each section is a video-game selection menu; the same aesthetic continues through the tools.
- PS1/PS2 low-poly geometry, rough/pixel textures, beveled cobalt controls, cyan highlights, visible keyboard focus and CRT-style scanlines.
- Sky intro and slowly moving clouds on the menu.
- Align VIEW with JUKE; add a soft animated glow and selection brackets.
- The blue-armored reference character defines the style only.
- Use the recovered polygon head and the artist on the right of the supplied photo as the actual character references. The suit direction is white, with blue on top of the afro.
- Image Chat analyzes characters/images, rather than editing code.
- Repository connects to GitHub.
