# Seven practical prompts, adapted from the video

These are **original prompts**, designed for the LESS app and the owner's projects, not transcripts of the video's exact wording.

## 1. Clean TV UI
"Research my exact television make, model, OS and supported launcher SDK. Show the smallest reversible option for an ad-free, user-controlled home screen. Do not uninstall any system apps. Give me a browser UI prototype and a precise model-specific feasibility check before native deployment."

## 2. Hardware adaptation
"For my [exact device] and [firmware version], identify documented customization points, recovery procedure, available memory and restrictions. Propose one reversible change with backup and a verification check. Keep other functions untouched."

## 3. AI + Blender motion
"Create an original 12-second 3D intro showing [subject] in [style]. First return a four-shot storyboard and material palette. Next create a Blender Python script using only procedural geometry, lights and cameras. Render a low-res preview, list frame count and Blender version."

## 4. Information filter
"Review only the messages or feed items I provide. Sort into urgent, important, later, and optional, citing what specifically makes each item useful. Suggest actions but take none without my approval. Avoid exposing confidential data in local prototypes."

## 5. Replace app chores with agents
"Choose the smallest repeatable workflow from this app: [task]. Represent it as input → rule → output → check. Draft a reusable instruction and optional local script, without subscriptions or new accounts unless required."

## 6. Edit out video filler
"Analyze my transcript by sections and identify exact excerpts that are repeated, tangential, overly long, or missing clarity. Label each as remove, tighten, keep, or fix. Preserve the main idea and speaker intent. Never alter the original footage; output a reviewable edit decision list."

## 7. Minimal internal software
"Map the five functions I actually use from [app]. Build just those functions in a private local-first web interface, with data export and clear modular navigation. Show editable UI before any cloud connection or production deployment."
