# Reusable Template Brief — Connected Portal Build

Use this project as the reference for future small connected portal/dashboard builds.

## Preserve

- End-to-end structure from hardware -> OS -> connectivity -> launcher -> app UI -> media -> autostart -> verification.
- Safe allowlisted local app launcher pattern.
- Spotify PKCE pattern with no committed client secret.
- Touch-first portal information architecture.
- Baseline-lock and change-only visual workflow.

## Replace per project

- reference video/image,
- device name,
- screen size/orientation,
- target hardware,
- app tile list,
- audio hardware,
- brand name,
- visual style,
- launch commands.

## Required output for a future portal

- README
- architecture diagram
- end-to-end setup guide
- media/auth setup guide
- app allowlist
- launcher service
- portal UI
- autostart instructions
- security notes
- test checklist
- coding-agent prompt
- Figma brief before visual finalization

## Creation rule

When a reference image/video establishes the appearance, do not finalize a new visual direction from assumptions. Produce or inspect a visual target first, get approval, then lock that baseline and make only requested changes.
