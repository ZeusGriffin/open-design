# Be More Agent — Original Hardware BOM

Video creator: brenpoly. Build stack: Ollama Gemma 3 + Moondream, Whisper.cpp, Piper, OpenWakeWord, Python GUI.

| Component | Original build |
| --- | --- |
| Pi | Raspberry Pi 5, 16 GB |
| Camera | Pi Camera Module v2 |
| SSD carrier | Pimoroni NVMe Base Duo |
| UPS | Geekworm X1203 5 V shield |
| Screen | Freenove 5-inch touchscreen |
| Buttons MCU | Adafruit Feather 32u4 Basic Proto |
| Audio | Mini USB mic and USB 2.0 speaker |
| Buttons | Seven 6 mm switches |
| Magnets | Sixteen 5 × 2 mm |
| Power cell | 3.7 V lithium-ion (specific pack unverified) |
