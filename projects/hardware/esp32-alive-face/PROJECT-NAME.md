# FIRMA

Official project name: **FIRMA**.

Former working titles: Tamagotchi New Juke / ESP32 Alive Face.

Scope: animated digital companion with separate firmware targets for LILYGO T-Display S3 and small ESP32-C6 OLED, plus a SwiftUI iPhone app. Other hardware variants remain future adaptations.

Current source location: `projects/hardware/esp32-alive-face/` (legacy directory retained to preserve links).

Status: prototype code committed; board pinouts, build verification and physical testing pending.
