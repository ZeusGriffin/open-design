# New Juke iPhone — SwiftUI starter

This is an original source-code prototype, not an installed app, IPA or App Store release.

## Build
1. On a Mac with Xcode, create an iOS App project named NewJuke using SwiftUI and Swift.
2. Replace the generated App source with NewJukeApp.swift. Remove the original @main declaration so only one remains.
3. Choose your Apple development team and connected iPhone or simulator.
4. Build and run. Confirm the eyes blink, Feed/Play/Rest buttons change stats, and stats persist on relaunch.

## Scope
Offline touch-based animated pet with saved food, joy and energy. No real-time decay, sound, music-reactive input, or hardware synchronization yet.

## Future
Shared pixel-art assets, sound effects, music-reactive expressions, optional ESP32 companion synchronization. iPhone app and ESP32 firmware remain separate targets.
