# CyberDeck iPhone 15 — preparation kit

Source: https://github.com/cobanov/cyberdeck
Target: standard iPhone 15 (not Pro or Plus)
Status: DESIGN PREP ONLY — no STL validated or printed.
Phone nominal dimensions: 147.6 x 71.6 x 7.8 mm.

## Goals
1. Preserve upstream source and license attribution.
2. Build parametric phone tray for standard iPhone 15.
3. Reuse keyboard and hinge architecture from upstream where compatible.
4. Produce slate first, then clamshell.
5. Test fit before printing final enclosure.

## When at computer
Clone upstream separately, inspect CAD scripts and licenses, compare keyboard dimensions, run OpenSCAD/CadQuery dependencies as applicable, export test coupon/tray STL, measure fit, then iterate.
Never assume the original iPhone 12 mini dimensions fit the iPhone 15.
Do not overwrite BASE or Cardputer projects.
