# JUKEBOXX / Johnny Jukebox — Motion Studio
Status: Starter code prepared; render unverified.
GitHub folder: https://github.com/ZeusGriffin/open-design/tree/main/projects/johnny-jukebox-motion
Video reference: https://youtu.be/lCf2Al478lY

## Goal
Create repeatable launch-film motion graphics and social video assets for Johnny Jukebox. Keep the PS1-style head concept and original artwork separately tracked.

## Current baseline
Two Remotion compositions: JohnnyLaunch (1920×1080, 10s) and JohnnySingle (1080×1920, 8s).
Text, colors, and artist are editable props. No real music or portrait included.

## Next verification
npm install; npm run compositions; npm run dev; render both clips; inspect first/middle/last frames and audio silence.
Then insert approved Johnny head and five singles.

## CLUB monetization hypothesis
Use teasers to route fans to a clearly defined offering (streaming, merchandise, ticket sales or membership). Track visits, conversions, cost and revenue; no profit guarantee.

## STACK / lean build
Goal → Context → Baseline → Smallest edit → Verify → Record result → Rollback.
Avoid unnecessary dependencies. Do not confuse concept mockups with verified exports.
