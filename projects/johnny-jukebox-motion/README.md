# Johnny Jukebox — Motion Graphics Studio (starter)
Original, editable launch video templates. This is **not** source code copied from the referenced YouTube video.

## Run
1. Install Node.js LTS.
2. `npm install`
3. `npm run dev` to preview in Remotion Studio.
4. `npm run render:launch` or `npm run render:single` to export MP4.
5. Edit `src/root.tsx` defaultProps for artist, headline, subtitle and colors.
