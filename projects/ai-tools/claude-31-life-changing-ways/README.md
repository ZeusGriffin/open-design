## Reusable pattern from the video

For device/build prompts, use this five-part frame:

1. **Device/context** — exact model, files, photos, measurements, or dataset.
2. **Task/access route** — USB, Wi-Fi, ADB, SSH, API, local files, etc.
3. **Build/outcome** — what should exist when finished.
4. **Safety** — backup first, read-only where possible, reversible changes.
5. **Verification loop** — one change at a time, test, compare, report.
