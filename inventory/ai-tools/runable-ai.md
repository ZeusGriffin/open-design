## Patterns worth recreating in our own system

1. **One command center** — one prompt starts research, planning, creation, and delivery.
2. **Artifact tiles** — fast entry points for Apps, Websites, Slides, Reports, Images, Video, Documents, and Automations.
3. **Persistent project context** — keep brand rules, prior decisions, files, and repository state attached to the project.
4. **Repository-aware building** — inspect the current codebase, preserve the approved baseline, make change-only edits, test, and commit.
5. **Shared skill catalog** — the same reusable skills work across Codex and Claude.
6. **Plugin/connectors layer** — GitHub, Library, Obsidian, cloud files, messaging, and future hardware workflows.
7. **Controlled execution loop** — brief → plan → create → preview → verify → save.
8. **Scheduled and recurring work** — allow approved workflows to run later or repeat.
9. **Unified output shelf** — keep code, documents, presentations, images, PDFs, and build notes together.
10. **Mobile-first control** — launch jobs, review previews, and approve delivery from iPhone.

## How it maps to the existing By Zeus workflow

- **Karpathy Method** supplies the preflight: Spec, Verifier, and Implementation Plan.
- **Controlled Creation Loop** supplies Baseline Lock, Creation Gate, Change-Only, testing, and Delivery Verification.
- **GitHub** remains the code and version source of truth.
- **Library and Obsidian** hold durable deliverables, references, and searchable project records.
- **BLINK / By Zeus** supplies the original visual language and authorship; Runable branding and assets are not reused.
