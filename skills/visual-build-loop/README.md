# Visual Build Loop

Reusable skill for screenshot-driven, step-by-step computer work.

Reference video: https://youtu.be/M5KOgtk9VfI

Core loop:

SCREENSHOT -> INSPECT -> NEXT ACTION -> EXECUTE -> SCREENSHOT -> VERIFY -> REPEAT

This is useful when written instructions become stale because the real screen determines the next step. It is intended for app building/testing, firmware setup, Raspberry Pi/Cardputer projects, browser configuration, debugging, and other visual workflows.

See SKILL.md for the operating rules.
