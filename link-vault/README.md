# Link Vault

A standalone, mobile-friendly web app containing the 10 free websites featured in **“Free Websites That Are Secretly Better Than Paid Apps.”**

## Included tools

- myNoise
- SuperCook
- Hemingway Editor
- JustWatch
- Ninite
- draw.io
- Photopea
- Bitwarden
- Perplexity
- Scribe

## Features

- Search by tool, use, or category
- Category filters
- Favorites saved locally in the browser
- One-tap launch buttons
- Responsive mobile/desktop layout
- No build step required

## Run it

Open `index.html` in any modern browser.

The app is fully standalone and uses plain HTML, CSS, and JavaScript.
