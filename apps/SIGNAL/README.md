# SIGNAL

BLINK / BY ZEUS

Mobile-first wireless map/search app inspired by WiGLE-style mapping, with OLED-black tap-password startup flow.

Current approved startup visual: tiny glowing circles appear near center, bloom into irregular puddle/sonar ripples, then fade into pure black. Password flow: CREATE YOUR PASSWORD → 3 → 2 → 1 → tap count → 1 tap YES / 2 taps NO → handshake → CONNECTED → SIGNAL.

Camera phase is intentionally deferred.
