# 925 Studios — Tap Wallpaper Maker

A mobile-first wallpaper creation concept for building original interactive wallpapers that respond to touch and device movement.

**Brand:** 925 Studios  
**Creator credit:** Made by ZUZ  
**Reference:** https://youtu.be/ijF3A3pl8NE

## Goal

Let a user import or create a wallpaper, divide it into depth layers, preview touch/parallax motion, customize the effect, and export a high-resolution phone wallpaper package.

## Core experience

1. Choose a photo or generated background.
2. Automatically suggest foreground, middle, and background layers.
3. Let the user correct masks and depth order.
4. Select an interaction: tap pulse, touch-follow, parallax tilt, drifting clouds, light sweep, or subtle zoom.
5. Preview the result inside an editable iPhone-style frame.
6. Adjust motion strength, speed, direction, loop, focus point, and reduced-motion behavior.
7. Export the still wallpaper, separated layers, motion settings, and a short preview.

## First target

- iPhone 15 portrait canvas: 1179 × 2556
- Crisp high-definition rendering
- Touch response under 50 ms where the device/browser permits it
- Subtle motion that never makes the wallpaper look like a game
- All artwork must be original or supplied/licensed by the user
