# Product Spec

## Working name
Tap Wallpaper Maker

## Owner
925 Studios

## Credit
Made by ZUZ

## Milestones

1. **Project shell:** mobile-first canvas, project creation, presets, local save.
2. **Layer editor:** import, masks, depth order, edge refinement, gap fill.
3. **Motion engine:** tap, touch-follow, tilt, cloud drift, light sweep, living still.
4. **Preview:** editable phone frame, full-screen mode, sensor permission and fallback.
5. **Export:** still, layered ZIP, JSON recipe, preview video, reopenable project.
6. **Verification:** automated checks plus real-device visual and performance testing.

## Definition of done

The concept package is complete when the repository contains the source reference, a build-ready prompt, requirements, constraints, and objective acceptance checks. The eventual app is complete only after it passes the acceptance checks in MASTER_PROMPT.md and real-device testing.

## Known uncertainty

The YouTube page was not reachable from the current research environment, so this package does not claim a frame-by-frame extraction of the video. The link is preserved as a reference, and the product specification is based on Zee’s explicit request for a tap-controlled, custom wallpaper maker.
